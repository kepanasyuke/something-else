# Rubik's Cube Simulator

Интерактивный 3D-симулятор кубика Рубика на React, Three.js и React Three Fiber.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. В режиме «Профи» доступен Stackmat-таймер и статистика Ao5/Ao12. В режиме «Новичок» включаются рентген-режим и визуальная подсказка следующего хода. Слои кубика можно вращать свайпом или перетаскиванием мыши.

## Сборка

```bash
npm run build
```
