# something-else

## Простыми словами

Это папка с несколькими независимыми экспериментами: поисковый сервис на FastAPI и Elasticsearch, симулятор разрушения виллы в Unity, шейдеры жидкости и ртути, приложение на React.

Каждый проект живёт в своей папке и запускается отдельно — здесь собраны работы, которые не тянут на отдельный репозиторий, но показывают разный стек.
