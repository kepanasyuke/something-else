# STRATU // Visual Engine

Новый React/Vite-проект для визуального индексирования изображений. После демонстрационной авторизации доступны четыре фильтра, сортировка карточек по евклидову расстоянию и свободное перетаскивание изображений по рабочей области.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Для входа подойдут любой корректный email и любой пароль.

## База изображений

Демо-данные находятся в `src/data/imageDb.json`. Для локальных изображений создайте `public/assets/raw-images/`, добавьте JPG, PNG или WebP и запустите:

```bash
npm run generate-db
```

Генератор создаёт записи с базовыми метриками и локальными путями. Палитры можно дополнить отдельным анализатором изображений позже.
