# Guilbert Photons

Guilbert Photons — локальная научная обсерватория документов. Она объединяет FastAPI-поиск, фазовую визуализацию состояния запроса, мультиязычную навигацию и экспорт результатов для работы с астрономией, астрофизикой, космологией, квантовой физикой и космической наукой.

## Возможности

- Поиск по 5 021 локальной записи.
- Поиск на русском, французском и немецком языках.
- Фазовая анимация с поддержкой режима уменьшенного движения.
- Экспорт в JPEG, GIF, XLSX и PPTX.
- Метаданные OpenAlex, ссылки на источники и отметка открытого доступа.

## Локальный запуск

```bash
make install
make run
```

Откройте `http://localhost:8000`. Команда `make check` выполняет проверку синтаксиса и health endpoint. Команда `make build-corpus` обновляет часть корпуса из OpenAlex.

## Данные и языки

Записи OpenAlex являются библиографическими данными для поиска: проект хранит заголовки, аннотации, авторов, идентификаторы и ссылки, но не распространяет полные тексты статей. Дополнительные записи на русском, французском и немецком — короткие навигационные аннотации со ссылками на открытые научные источники.

Подробнее о визуальной системе и взаимодействиях — в `DESIGN.md`.
