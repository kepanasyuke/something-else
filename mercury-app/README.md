# Mercury App

Интерактивная WebGL-сцена с эффектом жидкой ртути и серебра. Наводите курсор и удерживайте кнопку мыши или касайтесь экрана, чтобы нагревать поверхность и запускать ударную волну.

## Запуск

Из папки `mercury-app` запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000> в браузере. Локальный сервер нужен, потому что шейдеры загружаются через `fetch()`.

## Структура

- `index.html` - HTML-каркас и подключение Three.js.
- `src/main.js` - события, инерция курсора и жизненный цикл сцены.
- `src/shaders/vertex.glsl` - вершинный шейдер.
- `src/shaders/fragment.glsl` - шум, деформация и рендеринг металла.
