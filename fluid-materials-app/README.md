# Fluid Materials App

Интерактивная WebGL-сцена с тремя материалами: гелий, вода и дымчатый газ. Переключайте материал кнопками и возмущайте поверхность мышью или касанием.

## Запуск

```bash
python3 -m http.server 8001
```

Затем откройте http://localhost:8001.

## Структура

- `src/main.js` - раннер, события и переключение материалов.
- `src/shaders/common.glsl` - общий шум, деформация, нормали и виньетка.
- `src/shaders/helium.glsl` - светлый газовый материал.
- `src/shaders/water.glsl` - сине-зелёная вода с френелем.
- `src/shaders/gas.glsl` - дымчатый материал.
